Dabei gibt es in dem Paket folgende(der Schnelligkeit geordnet)

SIMDArrayNorm.jl -kann alle Ordnungen benutzen
OhneGeobucket.jl -kann alle Ordnungen benutzen
AlteStruktur.jl -einfache Division mit alter Struktur
